# حساباتي السودان (Hisabati Sudan) 🇸🇩
### المنصة المحاسبية الذكية ونقاط البيع الصوتية للسوق السوداني

نظام محاسبي متكامل ونقاط بيع (POS) مصمم خصيصاً لتلبية احتياجات التجار وأصحاب المحلات والأنشطة التجارية في السودان، مع دعم المساعد الصوتي الذكي باللهجة السودانية الدارجة، الأوزان والوحدات التقليدية (الرطل، الكيلو، الجوال، الدستة، الكرتونة)، وحماية الأرباح عبر نظام الصلاحيات المتقدم (RBAC).

---

## 🌟 أبرز الميزات والوظائف

### 1. المساعد المحاسبي الصوتي الذكي (Voice POS)
- **فهم اللهجة السودانية الدارجة**: يفهم عبارات مثل «بعت اتنين كيلو سكر وكيلو شاي»، «3 رطل زيت صباح ودستة صابون»، «جوال سكر 50 كيلو وباكتين دقيق سيقا».
- **عدم تخمين الأسعار**: يجلب الأسعار الحقيقية من المخزون حصراً دون اختراع، ويطلب التوضيح فوراً عند ورود أصناف غير محددة (مثل «جيب لي خمسة من داك»).
- **التعلم وقاموس المصطلحات**: قاموس مدمج قابل للتطوير يتيح للتاجر إضافة مصطلحات جديدة وربطها بالمنتجات.

### 2. منظومة الأوزان والوحدات السودانية
- يدعم: الكيلوجرام، الرطل (450 جم تقريباً)، الأوقية (37.5 جم)، الجوال/الشكارة (50 كجم)، الكرتونة، الدستة (12 حبة)، الباغة/الجركانة (4 لتر)، الكوز، والربطة.
- محرك تحويل ذكي يحسب سعر نصف الكيلو أو الرطل تلقائياً، مع دعم أسعار الجملة والقطاعي المخصصة.

### 3. إدارة المخزون اللحظية
- متابعة الأرصدة ورفوف التخزين.
- تنبيهات نواقص الرفوف وحد الطلب.
- تسجيل المشتريات والتوريد والتوالف ومرتجعات الفواتير.
- حماية المخزون من الرصيد السالب دون إذن المدير.

### 4. الفواتير والطباعة الاحترافية
- قوالب طباعة للطابعات الحرارية (Thermal Receipt 80mm / 58mm) ومقاس A4 الرسمي.
- دعم طرق الدفع المتداولة في السودان: كاش، تطبيق بنكك (بنك الخرطوم)، تطبيق فوري (بنك فيصل)، والدفع الآجل (تتبع ديون العملاء).
- مشاركة الفاتورة عبر واتساب.

### 5. إدارة الموظفين والصلاحيات (RBAC)
- فصل صلاحيات الكاشير عن المدير والمالك:
  - **المدير / المالك**: اطلاع كامل على صافي الربح، تكلفة الشراء (COGS)، وتعديل الأسعار.
  - **الكاشير**: حجب أسعار الشراء وهوامش الأرباح، مع صلاحية إصدار الفواتير فقط.
- سجل تدقيق مالي وأمني (Audit Log) يوثق كل عملية مع اسم المستخدم والوقت.

### 6. لوحة التحكم وصافي الربح الحقيقي
- التزام صارم بالمعادلة المحاسبية:
  $$\text{صافي الربح} = \text{إجمالي المبيعات} - \text{تكلفة البضاعة المباعة (COGS)} - \text{المصروفات التشغيلية}$$
- تتبع المصروفات (إيجار، وقود مولد الكهرباء، نثريات).

### 7. قوالب متعددة للأنشطة التجارية
- البقالات والسوبرماركت (الأساسي).
- الصيدليات (تاريخ الصلاحية ورقم التشغيلة).
- المطاعم والكافيهات (وجبات، إضافات، شاي مقنن).
- ورش وصيانة السيارات وقطع الغيار (رقم القطعة، أجور اليد).
- الإلكترونيات والهواتف، الملابس، ومواد البناء.

## 🚀 طريقة التشغيل والإعداد

### المتطلبات
- Node.js (الإصدار 18 فما فوق)
- npm

### خطوات التثبيت والتشغيل
1. تثبيت الحزم:
```bash
npm install
```

2. تشغيل خادم التطوير:
```bash
npm run dev
```

3. بناء النسخة الإنتاجية:
```bash
npm run build
```

4. تشغيل الإنتاج:
```bash
npm start
```

## 🌐 النشر على Vercel

المشروع جاهز للنشر المباشر على [Vercel](https://vercel.com):

1. اربط المستودع بمشروع Vercel (Framework Preset: **Vite** — يُكتشف تلقائياً، و`vercel.json` يثبّت الإعدادات).
2. أضف متغيرات البيئة في **Project Settings → Environment Variables**:
   - `GEMINI_API_KEY` (اختياري — بدونه يعمل المحرك اللغوي المحلي للهجة السودانية تلقائياً)
   - `GEMINI_MODEL` (اختياري — الافتراضي `gemini-3.8-flash`)
3. ادفع إلى فرع `main` فيتم البناء والنشر آلياً.

**الواجهات البرمجية (API)** تعمل على Vercel عبر Serverless Functions في مجلد `api/`:

| المسار | الوصف |
|---|---|
| `POST /api/ai/parse-sale` | محلل اللهجة السودانية (Gemini + محرك محلي احتياطي) |
| `GET /api/health` | فحص حالة الخدمة |
| `POST /api/notifications/email/send` | مُرسل الإشعارات (واجهة محاكاة — للتطوير) |

> المنطق المشترك بين `server.ts` (تطوير محلي) ودوال Vercel موجود في مجلد `shared/`.

## 🔒 حماية مفاتيح الذكاء الاصطناعي (Gemini API)
- تتم معالجة طلبات الذكاء الاصطناعي حصراً عبر الخادم الخلفي (`server.ts` محلياً أو `api/ai/parse-sale.ts` على Vercel) عبر المسار `/api/ai/parse-sale`.
- في حال عدم توفر مفتاح `GEMINI_API_KEY`، يتولى المحرك اللغوي المحلي (Rule-Based Engine) معالجة اللهجة السودانية والأرقام والأوزان بدقة متناهية ودون أي توقف في الخدمة.
